Tutorial de Git

📘 Introducción a Git

¿Qué es Git?

Git es un sistema de control de versiones que permite registrar cambios en proyectos y trabajar en equipo.

Ramas

Las ramas permiten trabajar en nuevas funcionalidades sin afectar la versión principal del proyecto.

Comandos básicos

  • git init
  • git add .
  • git commit
  • git push
