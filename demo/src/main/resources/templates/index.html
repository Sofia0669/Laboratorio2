📘 Tutorial de Git

¿Qué es Git?

Git es un sistema de control de versiones que permite llevar un registro de los cambios en proyectos, especialmente en desarrollo de software.

Comandos básicos

  • git init → Inicializa un repositorio
  • git add . → Agrega archivos
  • git commit -m "mensaje" → Guarda cambios
  • git push → Sube cambios a GitHub

Ramas en Git

Las ramas permiten trabajar en diferentes versiones del proyecto sin afectar la principal.
